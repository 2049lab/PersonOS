This record covers the public repository's introduction and brand assets.
Runtime behavior is defined in the framework and API documentation.

## Platform

web

## Users

Developers evaluating and integrating long-term personal memory into agents.

## Product Purpose

PersonOS is an open-source Python framework that stores source evidence,
organizes personal context into episodes and atoms, connects related facts
across time, and retrieves relevant memories for an agent.

## Capabilities and Constraints

- The Python SDK and optional HTTP service are documented in this repository.
- Local SQLite is the default. Inference uses configured model endpoints.
- Recall may return retrieved material, an answer, or optional deeper search.
- Images and video identity workflows require separately configured backends.
- The framework is alpha. Historical benchmark numbers are not verified for
  the current revision and must not become headline metrics.
- GitHub sanitizes README HTML; navigation must remain real accessible links.
